# NXT AI

A from-scratch AI research project. No third-party AI inference APIs.

## Roadmap
1. Train a tiny character-level Transformer from random initialization using PyTorch on your PC.
2. Build a responsive GitHub Pages dashboard with Chat, Image and Video tabs.
3. Connect the dashboard to a locally hosted inference server through an explicitly configured endpoint.
4. Research and train image models separately; implement procedural animation export before attempting neural video generation.

**Status:** Initial project scaffold only. No model has been trained and no hosted inference endpoint exists yet. GitHub Pages cannot execute Python or host GPU inference.

**Hardware:** Training large language, image or video models requires much more compute than typical home PCs. Begin with a tiny model and small licensed dataset.
